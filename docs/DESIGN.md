# Интерфейс

Прототип из задания: MAX Web, двухпанельная структура мессенджера. Telegram используется как разрешённая в задании альтернатива. Это самостоятельная реализация, не точная копия и не официальный клиент MAX.

- Слева: заголовок «Чаты», создание чата, список с последним сообщением, отключение
- Справа: заголовок выбранного чата, история, поле сообщения, отправка
- Вход: apiUrl, idInstance, скрытое apiTokenInstance, подключение и отдельное демо
- Цвета: #fff поверхности, #f3f6fa фон чата, #2864ec акцент, #dce9ff исходящие, #e8f1ff выбранный чат, #18202f текст, #657086 вторичный текст
- Шрифт: системный sans-serif. Текст 15–16 px, подписи 12–13 px, заголовки 20–28 px
- Контролы: 44 px минимум, видимый focus, иконки Lucide с единым stroke 1.8, без дополнительных декоративных изображений
- На узком экране: список и переписка по очереди, кнопка назад; формы в доступном диалоге
- Демо всегда явно помечено; локальные сообщения не являются доказательством интеграции

Архитектура: App управляет авторизацией и отменой подключения; ChatSession управляет экраном; useChat управляет перепиской; api содержит проверяемый HTTP-адаптер и последовательный обработчик очереди. Секреты и переписка хранятся только в памяти. Закрытие/обновление страницы и отключение очищают их.
